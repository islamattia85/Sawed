# How Peakless talks

One page. Read this before writing any line someone will see in the app.

## Who we sound like

A friend who knows a lot about energy, sitting at your kitchen table with your bill. They're relaxed and straight with you. They don't oversell. They say "we" for Peakless and "you" for the person, every time.

## Rules

1. **Say it once, in the fewest words.** If a line still makes sense with half the words cut, cut them.
2. **No dashes for effect.** Use a full stop. "Switch online. It takes ten minutes." Not "Switch online — it takes ten minutes."
3. **Don't sell the app.** No "completely transparent", "in plain English", "independent", "instantly" or "in 30 seconds". Show it instead.
4. **Don't explain the screen.** If a chart needs "Above the line: …", fix the chart (add a legend or labels). Drop "Continue when you're ready" and "Tap here to…" unless someone would really get stuck.
5. **No neat pairs.** Avoid "X, not Y" and "X: Y" lines unless it's a real label. Too many in a row sounds written by a machine.
6. **Words from the bill, not the industry.**
   - Say: plan, night rate, standing charge, meter file, panels, how full
   - Avoid: tariff, TOU, simulation, model, kWp (except in My system details), curtailed, NPV, irradiance, HDF, arbitrage
7. **Buttons say what happens.** Use the person's words: "Show my best plan", "Use this quote", "Add my meter file". Don't add a → arrow.
8. **Honest about limits, without drama.** "These are estimates." Once, where it matters. Not under every number.
9. **Irish English.** Use "Teatime", "fitted", "dear" (meaning expensive) and "2–3 weeks". Don't write "10–15 working days".
10. **One line for one thing.** If two screens say the same thing, they use the same words.

## Before and after

| Before | After |
|---|---|
| Add an installer quote and we'll check it against our own model — not theirs. | Add an installer's quote and we'll tell you if it's fair. |
| How we calculate your best electricity plan and solar payback — completely transparent. | How we work it out |
| Both goals point to the same design for your home — an easy decision. | *(cut)* |
| Continue when you're ready. | *(cut)* |
| Removed — your model loses about €40 /yr | Removed. That's about €40 a year less. |
| Curtailed (lost — over export limit) | Wasted (over the export limit) |

## Words we use

| Use | Not |
|---|---|
| plan | tariff |
| meter file | HDF CSV, smart-meter data import |
| night rate, cheap hours | TOU window, off-peak band |
| what you'd pay | simulated annual cost |
| we work it out | the model calculates |
| sell back, what you export | export payments, CEG |
| 20-year value | 20-yr NPV |

## Checklist for new text

- [ ] Would a person say it out loud like this?
- [ ] No dash, no "X, not Y", no selling
- [ ] Under 20 words, or it really needs more
- [ ] Same word as everywhere else for the same thing
