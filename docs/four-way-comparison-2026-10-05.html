switcher.ie: what we found

Typed usage works like bonkers.ie. Asked for a yearly figure, switcher.ie splits it 54% day, 37% night and 9% peak, the standard smart-meter split bonkers.ie also uses. Its sums agree with the supplier's own estimated bills: Electric Ireland's Home Electric SST Saver 16% comes out at €1,443, against €1,445 on bonkers.ie and €1,447 on Electric Ireland's own estimate. Average error 4.4% across the plans it prices, close to bonkers.ie's 5.1%.

The meter-file upload doesn't use the file's shape, and reads half the use. For the typical home, the file holds 4,193 kWh. switcher.ie's own calculation shows "Your consumption (2,096 kWh)", split 1,132 day, 776 night and 189 peak. That is exactly half the total, laid on the same 54/37/9 split as a typed figure. The file's real split is 64% day, 23% night, 13% peak. Sorting the file the other way round gave the same result. For the other 11 homes we read only the bills, which were 35–50% too low across the board, consistent with the same halving. bonkers.ie, kilowatt.ie and Peakless all read the same files as 4,193 kWh. So a home that uploads its file gets bills about 42% too low on every plan, and a ranking that ignores when it actually uses power.

We used ESB Networks' "30-minute readings in kW" format, the file switcher.ie asks for. If real ESB downloads differ from our test files in some way switcher.ie expects, its upload may behave better for real users. It reads them as valid and gives no warning.

It lists both of Energia's offers. switcher.ie shows Smart Data at 27% and 23%, and Smart 24 Hour at 30% and 28%, all for new customers, all with the 12 October price change counted. bonkers.ie and kilowatt.ie show only the dearer 23% and 28% versions. This settles the Energia question from the last report: the cheaper offers carry on past 12 October, and Peakless prices them.

The rivals' "€ lost" now includes Energia's cheaper offers, which bonkers.ie and kilowatt.ie don't list. For the typical, large and work-from-home homes, Energia Smart 24 Hour 30% is the cheapest plan, and only switcher.ie and Peakless show it. switcher.ie still ranks it below Electric Ireland's SST plan, because its standard split puts too much use at night.

What changed in Peakless today

  • Meter files are priced day by day. A file used to become six two-month totals and one average day. Now each day of the year uses the recorded day nearest the same date, on the same weekday. Error against the true cost fell from 0.2–1.2% to 0.0–0.3%, and it picks the cheapest plan for all 12 homes.
  • Energia: the 27% and 30% offers stay, with a note that dearer 23% and 28% versions also exist.

Still open

  • Heat pumps when you type your usage (4.7% error, €38). The test heat pump home was built from our own assumptions, so it can't tell whether a new model is better. It needs real heat pump meter files.
  • Solar plus battery when you type your usage (€147). The battery's grid-charging assumption decides it.

How it was run

switcher.ie was driven through its public comparison form (robots.txt allows it): electricity only, Pinergy as the current supplier, urban or rural, smart meter, direct debit, online billing, all plans (not only those switchable through switcher.ie), no cashback. Typed runs entered the yearly kWh, plus yearly export for the solar homes. File runs uploaded the same half-hourly ESB-format file used for the other sites. Results were read from the page, with each plan's supplier taken from its logo, and 25 named plans were matched to Peakless's list. The true cost, the homes and the scoring are those of the three-way report, recomputed with today's prices.
